# Five-minute local demonstration

Build and start with `uv run --locked python scripts/reproduce.py --serve`, or
launch the existing profile manifest as described in the README. Open
http://127.0.0.1:8765. This walkthrough uses real historical WSL inputs;
it makes no claim about current squad membership or transfer availability.

1. **Trace a profile.** Search Maya Le Tissier and choose the Manchester United
   team spell. Explain validated elapsed minutes, CB usage and peer eligibility.
   Inspect a complete activity metric beside an incomplete passing metric. Point
   out that coverage below 100% can suppress the full metric, rather than becoming
   a made-up zero. Expand Data coverage to inspect the source revision and profile
   manifest. The exact definitions live in [FEATURES.md](FEATURES.md).
2. **Compare records.** Open Player Comparison. Compare Maya Le Tissier and Guro
   Bergsvand. Add Ella Toone as a third player: the AM/CB warning makes clear that
   percentiles use different benchmarks. Raw values keep their native units;
   percentiles do not make different tactical roles interchangeable.
3. **Explain a neighbor.** Open Similar Players and choose Maya Le Tissier.
   Inspect the first neighbor's metric differences and distance contributions.
   Explain candidate-only standardization, self-exclusion and the transformed
   proximity index. A nearby event vector does not establish equal ability.
4. **Change a requirement.** Open Recruitment Search and choose CB defensive
   activity. Rank candidates, inspect the normalized priorities and a candidate's
   contribution details. Change Interceptions from 3 to 1 and rerun. Explain why
   changing priorities can change scores/ranks while the full reference benchmark
   remains fixed for candidate filters. These are illustrative weights.
5. **Show an honest unavailable outcome.** Choose AM creation activity and rank.
   There are too few complete peers, so no candidate score is invented. Age,
   market value and contracts remain unavailable. Finish with the distinction
   between passing engineering checks and unperformed expert/predictive review.
