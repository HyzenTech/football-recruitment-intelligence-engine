# Public V1 release scope

The public repository distributes original MIT code, configuration, synthetic
tests, engineering documentation, aggregate verification receipts and empty-state
interface/architecture images. Provider data and the attribution logo are
separately governed; the logo is used solely for source credit.

## Explicitly excluded

- Raw events, lineups, match lists, provider caches and database extracts.
- The 609 derived player/similarity/ranking JSON payloads and their export manifest.
- Screenshots containing player statistics, match footage and private review notes.
- The detailed cross-competition inventory CSV and Markdown table.
- Credentials, local environments and user-specific filesystem paths.

Historical baseline counts and methodological conclusions in documentation are
research findings, not a redistributed player database. No commercial exploitation,
provider endorsement, professional scouting validation or general accuracy is claimed.

## Reproduction and static interface

Use the original provider URLs only after reviewing DATA_LICENSE.md and provider
terms. Registration has not been completed by this project; the old registration
route now redirects to a product page. No registration or contact was submitted
on the user's behalf. Reproduction downloads directly from the provider into
ignored local storage. Source files alone do not provide a dataset.

The static interface/exporter remains available for local inspection. Its contract
is LOCAL_PREVIEW_ONLY_RIGHTS_PENDING. This release does not host it with real data,
alter that contract or imply that hiding a download button grants redistribution rights.

All 65 frozen V1 source/config/test/script files match BASELINE_PROVENANCE.json.
Only presentation, documentation and release packaging were adjusted. Earlier
Stage B/C/G reports are historical local checkpoints; this document defines the
current public scope. V1.1 has not started.
