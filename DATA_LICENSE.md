# Code and provider-data rights

The user selected **MIT** for the project's own code during Stage B on 1 October
2026. See [LICENSE](LICENSE). This grant does not apply to provider data, logos,
footage or third-party content. It does not authorize commercial exploitation
of provider-derived analysis. The public release distributes original code and engineering documentation only.

Provider data is governed independently. StatsBomb's [pinned Public Data User Agreement](https://github.com/hudl/open-data/blob/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb/LICENSE.pdf) allows research/analysis subject to its terms, restricts redistribution/provision of data and commercial exploitation of both data and derived analysis, and requires the StatsBomb logo on published analysis. The README also asks for StatsBomb source credit. Review the resource-centre registration request before future ingestion; no user registration has been performed.

Do not commit raw JSON, provider caches, event-row exports or database extracts. Keep immutable bytes locally and download directly from the official pinned provider paths. Any public analytical demonstration must be noncommercial, source-grounded and properly attributed. Commercial use, serving raw data or redistribution needs separate provider permission.

football-data.org's [terms](https://www.football-data.org/client/register) require visible provider attribution and secret credentials. Its API access does not confer team-crest/photo rights or a general redistribution licence. No football-data.org data is included here.

The audit files contain findings and coverage/provenance metadata, not event rows. Data rights are not changed by writing canonical schemas, calculating derived metrics or selecting a licence for this project's code.

## Static demo publication boundary

Every JSON asset served by a static demo is publicly accessible, even without a
download button. The agreement does not explicitly grant a general redistribution
licence for aggregate player-metric JSON/CSV. Resolve the exact public field
inventory and obtain adequate provider-specific clarification/permission where
necessary. User approval cannot expand provider rights.

Published analysis requires source credit and the official StatsBomb logo.
The official attribution logo is included with recorded provenance. Screenshots
containing player statistics and all derived player-data files are excluded from
the public release. Provider registration has not been completed; the legacy
registration link redirects to a product page. Local users must review provider
terms and the current registration route before obtaining provider inputs.
